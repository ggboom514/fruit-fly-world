# 果蝇世界

一块覆盖整个桌面的透明画布，上面生活着一群会繁殖、会长大、会死、会烂掉的果蝇。

它们不是会动的壁纸：每只有自己的基因组、体重、寿命和记忆。它们会闻到食物的味道飞过去、落在果子上拱来拱去，会为了一颗苹果抢座位、抢不到的会饿死；你拍死一只，尸体会留在原地慢慢腐烂掉价。你养大它们、把它们卖成钱、再用钱买工具养出更贵的。

**Windows x64 ｜ Electron ｜ MIT**

### 怎么知道有没有新版本

游戏**自己会查**。点面板上的**齿轮图标**打开「设置」，那张卡上有一行
`版本 1.28.0` 和一颗「检查更新」：

- 启动后**静默**查一次。没网、地址不通都只是算了，不会弹任何东西 ——
  桌宠一开机弹一句「检查更新失败」是最讨人厌的做法
- 有新版本时那一行会变金色，底下多出一颗「去下载」，点了用系统浏览器打开下载页
- 想手动查就点那颗「检查更新」

> ⚠ 发包的人**必须**配一个地址，否则这一行会显示「未配置更新地址」，
> 按钮是灰的。见下面「发布新版本」。


### ⚠ 第一次打开会被 Windows 拦一下

> **Windows 已保护你的电脑**

这是**正常的**，不是病毒。弹出的原因是这个程序没有买代码签名证书（一张证书一年几百美元，个人项目一般不买），Windows 对任何没签名的 exe 都会这么提示。

点 **更多信息** → **仍要运行** 即可。

### 退出的方法

退出走这几条路：

- 面板上的 **✕** 按钮
- `Ctrl + Shift + Q`（全局快捷键，**穿透状态下也能按**）
- 任务栏图标上右键 → 关闭窗口

另外两个全局快捷键，窗口点不到的时候用来救命：

- `Ctrl + Shift + F` —— 切换鼠标穿透
- `Ctrl + Shift + T` —— 切换窗口置顶

### 面板挡住了？收起来

面板标题栏上那个 **`–`** 把面板和罐子小窗**整块**收掉 —— 屏幕上只剩飞的虫，
右下角留一个圆形的小把手。

点一下把手，面板回来。**把手可以拖** —— 按住它拖到屏幕任何地方都行，
位置会记住，下次打开还在那儿（想回右下角就再拖回去）。

> 位置跟着存档走，所以点「重新开始」会把它一起复位回右下角。

### 两个开关到底管什么

| | 开（默认） | 关 |
| --- | --- | --- |
| **穿透** | 只有面板、罐子小窗这些 UI 接管鼠标，**画布一律穿透** —— 拿着喷火枪也能正常点桌面上的任何东西 | 鼠标整屏归游戏 —— 工具才点得动 |
| **置顶** | 浮在所有窗口之上 | 沉到所有窗口**之下**（仍在桌面之上），别的窗口能盖住它 |

> ⚠ **穿透默认是开的，所以刚打开时工具是「按不动」的** —— 点画布会点到桌面上。
> 想玩工具就先按 `Ctrl + Shift + F` 或点面板上的「穿透」把它关掉。
> 选中工具的那一刻，提示条会提醒你这一句。

### ⚠ 找不到窗口了怎么办

**点任务栏上那个图标。** 它是全屏透明的，没有标题栏可以点，所以那个图标是唯一能把
它叫回来的入口。

几种会「看起来消失」的情况，都靠它救：

- 按了 `Win + D` 或者点了任务栏最右边那条「显示桌面」—— 窗口会被**最小化**，
  而最小化的窗口在系统里是沉到**桌面底下**的（实测：桌面在 z 序 #47，最小化后的
  窗口在 #214），桌面上什么都看不见
- 关掉了「置顶」之后，它就是一个普通窗口，会被别的窗口盖住

> 开着「置顶」的时候 `Win + D` 是弄不掉它的 —— 那种状态下窗口被最小化会被立刻
> 抢回来。玩家既然开了置顶，意思就是要它一直在眼前。

## 怎么玩

### 一条生命

```
卵  →  幼虫  →  蛹  →  成虫
```

- **食物会腐烂**，也会被啃光 —— 啃光后原地留下一片污渍，要拿抹布擦
- **幼虫吃不到东西会饿死**（10~18 分钟没抢到座位），死了留一具不能烤的蛆尸
- **成虫有寿命**，会自然老死
- 成虫**一雌一雄碰到一起就会产卵**，基因按孟德尔那套传下去，还会自己突变

### 工具

| 工具 | 快捷键 | 干什么 |
| --- | --- | --- |
| 观察 | `Esc` | 纯看不打扰。鼠标基本穿透，但悬停在玻璃罐上时还能直接拖它 |
| 查看 | `V` | 点一下虫，弹出数据面板（基因、体重、售价、剩余寿命）。**罐子里的也能点** |
| 手套 | `G` | 拖动食物 / 蛹壳 / 成虫 / 尸体；把抓起来的成虫丢进玻璃罐或烤炉 |
| 苍蝇拍 | `F` | 拍面在指针的**左上方**，28px 半径内的虫全拍死 |
| 捕虫网 | `N` | 需购买。把附近成虫网进最近的玻璃罐 |
| 抹布 | `C` | 按住并**来回滑动**擦掉尸体 / 污渍 / 蛹壳。**按住不动是擦不掉的** |
| 喷水枪 | `W` | 需购买。滚轮改水线长短，`Shift`+滚轮转方向，按住左键冲 |
| 扫帚 | `B` | 按住把圈里的幼虫朝外扫开，滚轮调半径 30~200px。免费 |
| 打火机 | `R` | 需购买。按住左键扫过成虫就能**把它点着**，烧 5 秒后自动卖。判定很精确，得指着点 |
| 喷火枪 | `R` | 需升级。同上，但只烧 3 秒、卖价更高，而且**判定范围大一圈**（够得着得多） |

> ⚠ 喷**水**枪（`W`）冲掉地上的脏东西，喷**火**枪（`R`）把尸体烤熟卖钱 —— 名字只差一个字，别按错。

### 赚钱

一只果蝇值多少钱，是**体重 × 单价**算出来的，所以养得越久越值钱。尸体和罐里的成虫都能直接卖。

商店里这些（价格逐级累加）：

| 商品 | 价格 | 作用 |
| --- | --- | --- |
| 捕虫网 | $1 | 解锁 `N` |
| 放大镜 | $0.8 | 自己勾几个价值档，落在这些档里的成虫会亮起来 |
| 喷水枪 | $5 | 解锁 `W` |
| 警报器 | $2 | 罐中果蝇快寿终时高亮提醒 |
| 打火机 | $3 | 把成虫点着，烧 5 秒后按 **×1.2** 自动卖掉 |
| 喷火枪 | 再 $10 | 只烧 3 秒，**×1.5**，判定半径 26 → 60px |
| 烤炉 | $15 | **买断**。之后在投放里免费摆，最多同时摆 3 个 |
| 养蝇人 | $5 | 生态里一份食物都没有时自动投放 |
| 养蝇人 Lv.2 | 再 $17 | 再加自动出售，按价值档筛着卖 |

**投放弹窗**里的其他东西：

| 商品 | 价格 | 作用 |
| --- | --- | --- |
| 烤炉 | **免费**（要先在商店花 $15 买断） | 在屏幕上摆一个。手套抓成虫塞进去，**放进去就开始烤、每只各一条进度条，烤满的当场按 ×1.8 变成钱**。最多装 5 只、同时摆 3 个 |
| 玻璃罐 | 免费 | 摆一个。用捕虫网把果蝇网进去，罐中寿命 ×2 |
| 星空苹果 | $1 | **要先把彩蛋解开才会出现**（见文末）。幼虫吃了有 10% 概率长出「星云」 |

> ⚠ 烤炉和玻璃罐现在是**同一个形态**：商店买断（玻璃罐是白送的）→ 投放里
> 免费的「摆一个」→ 摆满了置灰。没买之前**那一行根本不出现** ——
> 摆一个按钮在那儿、点了却没反应，比不出现更让人困惑。
>
> ⚠ 1.27.0 之前烤炉是「每摆一个收 $5」，三次一共 $15。**总代价没变**，
> 只是付款次数从三次变成一次。老存档里已经摆着炉子的，读档时会自动算作已拥有。

投放弹窗里的食物栏有**解锁门槛** —— 看的是**累计总收入**（历史上一共赚到过多少钱，
只增不减），不是现在手里还剩多少：

| 食物 | 解锁条件 | 效果 |
| --- | --- | --- |
| 苹果 | **没有门槛** | 最基础的口粮，开局就能买 |
| 金苹果 | **累计总收入 $0.1** | 吃它的虫年龄推进 ×1.5，长成得比吃苹果快 |
| 星空苹果 | 解开彩蛋 | 见上面的剧透 |

> ⚠ **口粮永远不该被锁** —— 开局总财富是 0，把苹果也锁上就等于开局连一样
> 能买的东西都没有，而屏幕上的虫是会饿死的。
>
> 金苹果还没解锁时，投放面板里**没有那一行**，但底下会写一句
> 「金苹果：财富到 $0.100 解锁」——不然玩家在过线之前完全不知道有它，
> 到那一刻才发现凭空多了一行。
>
> ⚠ 开局屏幕上那份食物是**免费送的**，不受门槛管。

> ⚠ 用「累计总收入」而不是「手里还有多少钱」：后者会因为你买工具而缩水，
> 那样门槛和成就就会**倒退**，刚拿到的成就还会重放一遍。

> ⚠ **点火器和烤炉是两条完全不同的路**，别混：
> 点火器烧的是**活着的成虫**，烧完自动到账；烤炉烤的是**你抓进去的活蝇**，
> 一只一只各自烤好、各自到账。而地上的**尸体现在不能再烤了** ——
> 它只能按原价卖掉，或者拿抹布擦掉。

### 突变

**每颗卵各骰一次，和父母带什么完全无关** —— 没有遗传：

| 突变 | 概率 | 效果 |
| --- | --- | --- |
| ⚡ 疯狂 | 2.9% | 变得狂躁，会咬死同类；代价是寿命减半。**双眼泛着红光** |
| ◆ 点石成金 | 3% | 自身价值 ×1.3，附近成虫也跟着 +10%。**通体金色、带闪光** |
| ▣ 石化 | 2% | 体重 ×1.5（售价跟着涨），但**失去飞行**，只能在地上爬。**整只灰掉** |
| ◇ 结晶 | 1.1% | 全身透明 + 炫彩描边，价值 **×2** |
| ✧ 星云 | **抽不到** | 价值 ×1.2、**移动速度 ×2**。身体是星云上的一扇窗 |

> **每种突变长什么样，图鉴里画得出来**（每格左边那张小图就是拿场上真正的画法画的）。
> 还没见过的突变画成一个**认不出品种的暗影** —— 图鉴留得住「有这么个东西」，
> 留不住「它是什么样」。
>
> ⚡ 疯狂的眼睛本来是唯一一个看不出区别的：它只改行为。现在给它加了一圈红光，
> **场上也生效** —— 否则你根本认不出屏幕上哪只正在咬人。

> ⚠ 表里是**每一种各自**的概率。一颗卵是**四种各骰一次**，所以
> 「这颗卵是普通蝇」的概率是这四个的乘积 —— 现在约 **91%**，
> 也就是约 **8.7%** 的卵至少带一种突变。
>
> 想让变异更多或更少，别只改一个数：改一个对「普通率」几乎没影响
> （结晶砍一半也只把 91.3% 挪到 91.7%）。四个一起乘同一个系数才管用。

> ⚠ **突变不会遗传**：带结晶的父母，孩子照样只有 1.1% 是结晶。
> 所以稀有突变永远稀有，「养一批带某基因的种蝇」这件事不存在。
> 每颗卵都是一次独立的抽奖。

> 星云不进抽奖池 —— 唯一的来源是让**幼虫**吃「星空苹果」（见下面）。
> ⚠ 它**也传不下去**：一只星云蝇的后代全是普通蝇，它一死一卖就没了。
> 想一直养就得一直喂。

另外每只虫出生时还会骰一次**体格**（轻盈 95% / 超重 4.5% / 巨兽 0.5%），体格决定成长上限和飞行速度。售价按价值分六档：普通 → 罕见 → 稀有 → 极稀有 → 超级稀有 → 传说生物。

### 图鉴

顶部那颗「图鉴」按钮里列着这个世界**全部**的食物和突变，一格一样东西。
每格左边还有一张小图 —— **食物画的就是场上那颗果子，突变画的就是那只虫**
（同一个画法，所以认得出屏幕上那只是什么）。

**还没拿到的会置灰**，名字留着、说明换成「？？？」，小图画成一个暗影：

| | 什么时候点亮 |
| --- | --- |
| 食物格 | 苹果开局就是亮的；金苹果要累计总收入到 $0.1；星空苹果要解开彩蛋 |
| 基因格 | 你的世界里**出生过**带这种突变的虫（卵和幼虫也算），就点亮 |

> ⚠ 「点亮」**不跨局**：重置（或重开一局）会把图鉴一起清空，全变回灰的。
> 见下面的「重置」一节。
>
> 想把突变的样子画得不一样，改 `renderer/src/render.js` 里的画法就行 ——
> 图鉴那格调的是 `drawFlyIcon`，它底下复用场上那套 `drawFly`。

### 成就

达成的时候，**屏幕中上方**会滑进来一条横幅，停三秒再滑走：

| 触发 | 文字 |
| --- | --- |
| 解锁金苹果（累计总收入 $0.1） | `minecraft！` |
| 解锁星云苹果（点开彩蛋） | `小时的梦想` |
| 第一次见到「疯狂」 | `疯狂` |
| 第一次见到「点石成金」 | `财富自由` |
| 第一次见到「石化」 | `Bonjour` |
| 第一次见到「结晶」 | `贵族象征` |
| 累计总收入 $10 | `A5级别` |
| $100 | `A6级别` |
| $1000 | `A7级别` |
| $10000 | `无密恐之人` |

> 一口气同时达成好几个（比如攒到 $10 那一刻顺带跨过 $0.1）**会排队一条一条播**，
> 不会互相顶掉。已经拿过的不会重复弹。
>
> 图标是现画的 SVG，在 `renderer/assets/achievements/`（一共七 KB，
> 想改直接改那几个文件就行 —— 平涂 + 深色描边，没有渐变）。
>
> 「星云」突变本身**没有**成就 —— 用户没列。它照样进图鉴。
>
> 成就和彩蛋、图鉴记在同一个文件里（`unlock.json`），所以**重置会一起清掉**。

### 重置 = 真的从 0

面板上的 **重置** 按钮（和启动时的「重新开始」）会清掉：

- 果蝇、食物、**游戏币和已买的道具**
- **图鉴** —— 已发现的食物和突变全部变回灰的
- **彩蛋** —— 星空苹果重新锁上，要再点罐子十下
- **成就** —— 全部清空，包括四个财富档位（累计总收入也归零了）
- 存档文件本身

因为这一步不可逆，所以要过**三道**确认：先告诉你丢什么，再标红问一遍，
最后要你**手打「重置」两个字**才能点确定。

> 重置之后开局那几只**全是野生型**（不带任何突变），所以图鉴确实是空的。
> 想见到第一个变异，得等一代（二十多分钟），或者自己去喂星空苹果。
>
> 唯一不受影响的是**把手位置**和「正常 / 烦人」这些**偏好** ——
> 它们不是这一局养成的东西。

## 从源码跑

需要 [Bun](https://bun.sh)（或者 Node + npm）。

```bash
bun install
bun run start
```

### 打包

```bash
bun run dist
```

产物在 `dist/`：一个 NSIS 安装包和一个免安装版。

> 打包**不需要联网** —— `electron-builder` 配了 `electronDist` 指向本地的 `node_modules/electron/dist`。

### 发布新版本

分两件事：**把安装包传上去**，和**告诉老玩家有新版本**。

#### ① 传什么

| 文件 | 要不要传 | 说明 |
| --- | --- | --- |
| `FruitFlyWorld-Setup-x.y.z.exe` | ✅ | 安装版，大多数人下这个 |
| `FruitFlyWorld-Setup-x.y.z.exe.blockmap` | ✅ | 增量更新的差分文件。现在没用上，但少传了以后想加会**只能重传全部历史版本** |
| `FruitFlyWorld-x.y.z.exe` | ✅ | 免安装版，给不想装的人 |
| `说明.txt` | ✅ | 仓库根目录那份，给下载的人看的 |
| `win-unpacked/`、`builder-*.yml` | ❌ | 中间产物，传上去只是让人多下几百 MB |

> ⚠ **`version.json` 不传网盘。** 它是给**程序**抓的，而网盘不给程序抓 ——
> 它要待在 git 仓库里，走 raw 链接。见下一节。

#### ② 更新检查怎么工作

游戏查的是一个**你自己仓库里的 JSON**，格式就三行：

```json
{
  "version": "1.28.0",
  "url": "https://pan.quark.cn/s/……",
  "note": "这一版改了什么（可选，一句话）"
}
```

`bun run manifest -- "https://你的下载页" "改了啥"` 会照着 `package.json`
里的版本号生成它，写在**仓库根目录**的 `version.json`。

```bash
bun run manifest -- "https://pan.quark.cn/s/……" "1.29.0 改了什么"
git add version.json && git commit -m "版本清单" && git push
```

推上去之后，**催一下 jsDelivr 的缓存** —— 它对分支引用有 12 小时缓存
（响应头里写着 `s-maxage=43200`），不催的话玩家最坏要等半天才收到提示：

```
https://purge.jsdelivr.net/gh/<用户名>/<仓库>@main/version.json
```

然后浏览器打开下面这个，看到白底黑字的 JSON 才算数：

```
https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@main/version.json
https://raw.githubusercontent.com/<用户名>/<仓库>/main/version.json
```

> ⚠ **别手写 `version`** —— 「package.json 升到 1.29.0、清单忘了改」这种错
> 特别隐蔽：游戏老老实实说「已经是最新的」，你会以为更新检查坏了。
> 那个命令是从 `package.json` 读的，对不上才怪。

> ⚠ 版本号是按**数字段**比的，不是按字符串 —— 所以 1.10.0 比 1.9.0 新。
> （按字符串比的话 `'9' > '1'`，从 1.9 升到 1.10 的人就永远收不到提示。）

> ⚠ **仓库必须是公开的**，这两个链接才认。私有仓库返回 404，
> 而症状只是「检查更新失败」，很容易以为是代码坏了。

**为什么是两个地址**（在 `config.js` 里能填一串，按顺序试，第一个能用的说了算）：

| 地址 | 特点 |
| --- | --- |
| `cdn.jsdelivr.net` | 面向全球的 CDN，国内通常能开；但对**分支引用**有 12 小时缓存，内容可能旧半天 |
| `raw.githubusercontent.com` | 内容永远是最新的；但国内经常整个连不上 |

> ⚠ **两个都是时通时不通的**，这是实测结论，不是推测。同一台机器上隔半小时各测一次，
> 结果正好相反：一次是 jsDelivr 通、raw 三条连接全超时；另一次是 raw 1.3 秒就回来了、
> jsDelivr 连接直接被关闭。（`github.com` 本身两次都是通的，所以不是整个 GitHub 被封。）
>
> 这就是为什么要填两个 —— 单填任何一个，对一部分玩家来说这个功能就是死的。

jsDelivr 放第一位，因为**连得上**比「新」更重要：它连不上时玩家要多等一次 6 秒超时
才轮到 raw（启动那次是静默的，玩家感觉不到；手动点那次会多等几秒）。
两个都挂时，设置卡上会说「检查失败：……（2 个地址都试过了）」。

> ⚠ 缓存那 12 小时可以用 purge 接口催掉（见上），所以「不新」这件事是能治的；
> 而「连不上」治不了。这也是顺序这么排的另一个理由。

然后把它填进 `renderer/src/config.js`：

```js
update: {
	manifestUrl: [                              // 一个字符串也行，一串就按顺序试
		'https://cdn.jsdelivr.net/gh/<用户名>/<仓库>@main/version.json',
		'https://raw.githubusercontent.com/<用户名>/<仓库>/main/version.json',
	],
	downloadPage: 'https://……',                // 兜底下载页，清单里没写 url 时用它
	checkOnStart: true,                        // 启动后静默查一次
},
```

改完 **`manifestUrl` 是打包进 asar 的**，所以要重新打包才会生效。

> ⚠ 留空（或空数组）= 整个功能关掉：设置卡上显示「未配置更新地址」，
> 不发任何请求。自检里那条「检查更新」的断言走的是一条**本地小服务器**，
> 和这里配什么无关，所以留空也不会让 `bun run selftest` 变红。
> 自检模式下启动那一次请求**不会发**（见 `ui.initUpdate` 那段注释）。

### 检查

改完代码跑这三个：

```bash
bun run check      # 秒级语法检查
bun run sim        # 无头模拟器：把生态快进 120 分钟 + 几百条数值断言
bun run selftest   # 真的开一个窗口把 UI 跑一遍，读写 save.selftest.json，不碰你的真存档
```

`sim` 里有一批**写死的期望值**。改配置改到把断言弄红是**正常的** —— 那说明你改的东西确实影响了行为。

## 存档

```
%APPDATA%\fruit-fly-pet\save.json
```

> ⚠ 目录名是 `fruit-fly-pet`，**不是** `FruitFlyWorld` —— 这里以前写错了。
>   存档路径来自 `app.getPath('userData')`，而它取的是 package.json 里的
>   `productName`，没有才退回 `name`。`productName` 只写在 `build` 字段下面
>   （那是给 electron-builder 生成安装包名字用的），顶层没有，
>   所以**开发版和打包版用的是同一个目录**，都是 `name` 那个。

- 每 30 秒自动存一次，退出时也会存
- **卸载程序不会删这个文件夹**（`deleteAppDataOnUninstall: false`），想彻底重置就手动删掉它
- 应用内也有「重置」按钮，会弹**三道**确认

另外还有一个跨局的小文件，和主存档分开放：

```
%APPDATA%\fruit-fly-pet\unlock.json
```

里面就三个键：彩蛋解没解开（`star`）、图鉴里见过哪些突变（`seen`）、
已经拿到哪些成就（`achievements`）。

> ⚠ 说是「跨局」，其实**重置会把它一起清掉** —— 用户要的就是「重置 = 真的从 0」。
> 它和主存档分开只是因为「重新开始」（删掉 `save.json` 那种）不该把它带走。
>
> ⚠ 主进程那边对这个文件有**白名单**（`main.js` 的 `pet:save-unlock`）。
> 往里面加键的时候**必须同步改白名单** —— 漏了是**静默失败**：
> 渲染进程照写不误、拿不到任何错误，只有那个字段永远存不下来。

## 项目结构

```
main.js              Electron 主进程：窗口、鼠标穿透、全局快捷键、存档读写
preload.js           contextBridge 桥
renderer/
  index.html         面板与弹窗的结构
  style.css          全部样式
  assets/            图标等资源
  src/
    app.js           渲染进程入口与主循环
    config.js        ★ 几乎所有可调的数值都在这里
    world.js         生态规则（谁吃谁、什么时候死、怎么产卵、经济结算）
    entities.js      单只果蝇 / 幼虫 / 卵 / 蛹 / 食物 / 罐子 / 烤炉 / 粒子
    render.js        全部绘制
    nebula.js        星云贴图的加载 + 「世界锚定」的 pattern（星云苹果 / 星云突变）
    ui.js            面板、工具栏、弹窗、鼠标键盘
    market.js        售价公式、稀有度分档、商店
    mutations.js     突变抽取与倍率（⚠ 没有遗传，见文件头）
    save.js          存档
    utils.js         小工具函数
tools/
  check-syntax.js    语法检查
  simulate.js        无头模拟器 + 断言
  probe-fly.js       单只果蝇的调参探针（速度 / 转向）
  probe-forage.js    果蝇在离果子多远的地方落地（`bun run probe:forage`）
  make-icon.js       生成程序图标
  make-manifest.js   生成更新检查要的 version.json（`bun run manifest`）
```

仓库根目录还有两份要**提交进 git** 的小文件：

- `version.json` —— 更新检查要的清单，走 raw 链接被程序抓（`bun run manifest` 生成）
- `说明.txt` —— 给网盘下载的人看的，传安装包时一起传

**想改数值，先看 `renderer/src/config.js`** —— 按生态分节，注释里写清楚了每个数字是干什么的。

更细的调参速查见 [TUNING.md](TUNING.md)。
