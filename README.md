# 果蝇世界

一块覆盖整个桌面的透明画布，上面生活着一群会繁殖、会长大、会死、会烂掉的果蝇。

它们不是会动的壁纸：每只有自己的基因组、体重、寿命和记忆。它们会闻到食物的味道飞过去、落在果子上拱来拱去，会为了一颗苹果抢座位、抢不到的会饿死；你拍死一只，尸体会留在原地慢慢腐烂掉价。你养大它们、把它们卖成钱、再用钱买工具养出更贵的。

**Windows x64 ｜ Electron ｜ MIT**

### ⚠ 第一次打开会被 Windows 拦一下

> **Windows 已保护你的电脑**

这是**正常的**，不是病毒。弹出的原因是这个程序没有买代码签名证书（一张证书一年几百美元，个人项目一般不买），Windows 对任何没签名的 exe 都会这么提示。

点 **更多信息** → **仍要运行** 即可。

### 退出的方法

退出走这几条路：

- 面板上的 **✕** 按钮
- `Ctrl + Shift + Q`（全局快捷键，**穿透状态下也能按**）
- 任务栏图标上右键 → 关闭窗口

另外两个全局快捷键，窗口点不到的时候用来救命：

- `Ctrl + Shift + F` —— 切换鼠标穿透
- `Ctrl + Shift + T` —— 切换窗口置顶

### 面板挡住了？收起来

面板标题栏上那个 **`–`** 把面板和罐子小窗**整块**收掉 —— 屏幕上只剩飞的虫，
右下角留一个圆形的小把手。

点一下把手，面板回来。**把手可以拖** —— 按住它拖到屏幕任何地方都行，
位置会记住，下次打开还在那儿（想回右下角就再拖回去）。

> 位置跟着存档走，所以点「重新开始」会把它一起复位回右下角。

### 两个开关到底管什么

| | 开（默认） | 关 |
| --- | --- | --- |
| **穿透** | 只有面板、罐子小窗这些 UI 接管鼠标，**画布一律穿透** —— 拿着喷火枪也能正常点桌面上的任何东西 | 鼠标整屏归游戏 —— 工具才点得动 |
| **置顶** | 浮在所有窗口之上 | 沉到所有窗口**之下**（仍在桌面之上），别的窗口能盖住它 |

> ⚠ **穿透默认是开的，所以刚打开时工具是「按不动」的** —— 点画布会点到桌面上。
> 想玩工具就先按 `Ctrl + Shift + F` 或点面板上的「穿透」把它关掉。
> 选中工具的那一刻，提示条会提醒你这一句。

### ⚠ 找不到窗口了怎么办

**点任务栏上那个图标。** 它是全屏透明的，没有标题栏可以点，所以那个图标是唯一能把
它叫回来的入口。

几种会「看起来消失」的情况，都靠它救：

- 按了 `Win + D` 或者点了任务栏最右边那条「显示桌面」—— 窗口会被**最小化**，
  而最小化的窗口在系统里是沉到**桌面底下**的（实测：桌面在 z 序 #47，最小化后的
  窗口在 #214），桌面上什么都看不见
- 关掉了「置顶」之后，它就是一个普通窗口，会被别的窗口盖住

> 开着「置顶」的时候 `Win + D` 是弄不掉它的 —— 那种状态下窗口被最小化会被立刻
> 抢回来。玩家既然开了置顶，意思就是要它一直在眼前。

## 怎么玩

### 一条生命

```
卵  →  幼虫  →  蛹  →  成虫
```

- **食物会腐烂**，也会被啃光 —— 啃光后原地留下一片污渍，要拿抹布擦
- **幼虫吃不到东西会饿死**（10~18 分钟没抢到座位），死了留一具不能烤的蛆尸
- **成虫有寿命**，会自然老死
- 成虫**一雌一雄碰到一起就会产卵**，基因按孟德尔那套传下去，还会自己突变

### 工具

| 工具 | 快捷键 | 干什么 |
| --- | --- | --- |
| 观察 | `Esc` | 纯看不打扰。鼠标基本穿透，但悬停在玻璃罐上时还能直接拖它 |
| 查看 | `V` | 点一下虫，弹出数据面板（基因、体重、售价、剩余寿命）。**罐子里的也能点** |
| 手套 | `G` | 拖动食物 / 蛹壳 / 成虫 / 尸体；把抓起来的成虫丢进玻璃罐或烤炉 |
| 苍蝇拍 | `F` | 拍面在指针的**左上方**，28px 半径内的虫全拍死 |
| 捕虫网 | `N` | 需购买。把附近成虫网进最近的玻璃罐 |
| 抹布 | `C` | 按住并**来回滑动**擦掉尸体 / 污渍 / 蛹壳。**按住不动是擦不掉的** |
| 喷水枪 | `W` | 需购买。滚轮改水线长短，`Shift`+滚轮转方向，按住左键冲 |
| 扫帚 | `B` | 按住把圈里的幼虫朝外扫开，滚轮调半径 30~200px。免费 |
| 打火机 | `R` | 需购买。按住左键扫过成虫就能**把它点着**，烧 5 秒后自动卖。判定很精确，得指着点 |
| 喷火枪 | `R` | 需升级。同上，但只烧 3 秒、卖价更高，而且**判定范围大一圈**（够得着得多） |

> ⚠ 喷**水**枪（`W`）冲掉地上的脏东西，喷**火**枪（`R`）把尸体烤熟卖钱 —— 名字只差一个字，别按错。

### 赚钱

一只果蝇值多少钱，是**体重 × 单价**算出来的，所以养得越久越值钱。尸体和罐里的成虫都能直接卖。

商店里这些（价格逐级累加）：

| 商品 | 价格 | 作用 |
| --- | --- | --- |
| 捕虫网 | $1.2 | 解锁 `N` |
| 放大镜 | $1 | 自己勾几个价值档，落在这些档里的成虫会亮起来 |
| 喷水枪 | $2 | 解锁 `W` |
| 警报器 | $3 | 罐中果蝇快寿终时高亮提醒 |
| 打火机 | $3 | 把成虫点着，烧 5 秒后按 **×1.2** 自动卖掉 |
| 喷火枪 | 再 $8 | 只烧 3 秒，**×1.5**，判定半径 26 → 60px |
| 养蝇人 | $2 | 生态里一份食物都没有时自动投放 |
| 养蝇人 Lv.2 | 再 $5 | 再加自动出售，按价值档筛着卖 |

**投放弹窗**里还有一个花钱的（和食物、果蝇、玻璃罐放在一起）：

| 商品 | 价格 | 作用 |
| --- | --- | --- |
| 烤炉 | $5 | 在屏幕上摆一个。手套抓成虫塞进去，**放进去就开始烤、每只各一条进度条，烤满的当场按 ×1.8 变成钱**。最多装 5 只、同时摆 3 个 |
| 星空苹果 | $1 | **要先把彩蛋解开才会出现**（见文末）。幼虫吃了有 10% 概率长出「星云」 |

> ⚠ **点火器和烤炉是两条完全不同的路**，别混：
> 点火器烧的是**活着的成虫**，烧完自动到账；烤炉烤的是**你抓进去的活蝇**，
> 一只一只各自烤好、各自到账。而地上的**尸体现在不能再烤了** ——
> 它只能按原价卖掉，或者拿抹布擦掉。

### 突变

每只虫出生时按概率骰新发突变，父母带了的也会遗传（单方 20%，双方 36%）：

| 突变 | 新发概率 | 效果 |
| --- | --- | --- |
| ⚡ 疯狂 | 2.9% | 变得狂躁，会咬死同类；代价是寿命减半 |
| ◆ 点石成金 | 3% | 自身价值 ×1.3，附近成虫也跟着 +10% |
| ▣ 石化 | 2% | 体重 ×1.5（售价跟着涨），但**失去飞行**，只能在地上爬 |
| ◇ 结晶 | 1.1% | 全身透明 + 炫彩描边，价值 **×2** |
| ✧ 星云 | **抽不到** | 价值 ×1.2、**移动速度 ×2**。身体是星云上的一扇窗 |

> 星云不进新发抽奖池 —— 唯一的来源是让**幼虫**吃「星空苹果」（见下面）。
> 但它和别的突变一样**能遗传**（单方 20% / 双方 36%），所以养起来之后会留在种群里。

另外每只虫出生时还会骰一次**体格**（轻盈 95% / 超重 4.5% / 巨兽 0.5%），体格决定成长上限和飞行速度。售价按价值分六档：普通 → 罕见 → 稀有 → 极稀有 → 超级稀有 → 传说生物。

### 图鉴

顶部那颗「图鉴」按钮里列着这个世界**全部**的食物和突变，一格一样东西。

**还没拿到的会置灰**，名字留着、说明换成「？？？」：

| | 什么时候点亮 |
| --- | --- |
| 食物格 | 星空苹果要解开彩蛋才亮，其余的开局就是亮的 |
| 基因格 | 你的世界里**出生过**带这种突变的虫（卵和幼虫也算），就永久点亮 |

> 「点亮」是**跨局**的：见过一次就记在 `unlock.json` 里，点「重新开始」也不会变回灰色。
> 所以图鉴会一格一格攒满。

## 从源码跑

需要 [Bun](https://bun.sh)（或者 Node + npm）。

```bash
bun install
bun run start
```

### 打包

```bash
bun run dist
```

产物在 `dist/`：一个 NSIS 安装包和一个免安装版。

> 打包**不需要联网** —— `electron-builder` 配了 `electronDist` 指向本地的 `node_modules/electron/dist`。

### 检查

改完代码跑这三个：

```bash
bun run check      # 秒级语法检查
bun run sim        # 无头模拟器：把生态快进 120 分钟 + 几百条数值断言
bun run selftest   # 真的开一个窗口把 UI 跑一遍，读写 save.selftest.json，不碰你的真存档
```

`sim` 里有一批**写死的期望值**。改配置改到把断言弄红是**正常的** —— 那说明你改的东西确实影响了行为。

## 存档

```
%APPDATA%\fruit-fly-pet\save.json
```

> ⚠ 目录名是 `fruit-fly-pet`，**不是** `FruitFlyWorld` —— 这里以前写错了。
>   存档路径来自 `app.getPath('userData')`，而它取的是 package.json 里的
>   `productName`，没有才退回 `name`。`productName` 只写在 `build` 字段下面
>   （那是给 electron-builder 生成安装包名字用的），顶层没有，
>   所以**开发版和打包版用的是同一个目录**，都是 `name` 那个。

- 每 30 秒自动存一次，退出时也会存
- **卸载程序不会删这个文件夹**（`deleteAppDataOnUninstall: false`），想彻底重置就手动删掉它
- 应用内也有「重置」按钮，会弹二次确认

## 项目结构

```
main.js              Electron 主进程：窗口、鼠标穿透、全局快捷键、存档读写
preload.js           contextBridge 桥
renderer/
  index.html         面板与弹窗的结构
  style.css          全部样式
  assets/            图标等资源
  src/
    app.js           渲染进程入口与主循环
    config.js        ★ 几乎所有可调的数值都在这里
    world.js         生态规则（谁吃谁、什么时候死、怎么产卵、经济结算）
    entities.js      单只果蝇 / 幼虫 / 卵 / 蛹 / 食物 / 罐子 / 烤炉 / 粒子
    render.js        全部绘制
    nebula.js        星云贴图的加载 + 「世界锚定」的 pattern（星云苹果 / 星云突变）
    ui.js            面板、工具栏、弹窗、鼠标键盘
    market.js        售价公式、稀有度分档、商店
    mutations.js     基因与遗传
    save.js          存档
    utils.js         小工具函数
tools/
  check-syntax.js    语法检查
  simulate.js        无头模拟器 + 断言
  probe-fly.js       单只果蝇的调参探针（速度 / 转向）
  probe-forage.js    果蝇在离果子多远的地方落地（`bun run probe:forage`）
  make-icon.js       生成程序图标
```

**想改数值，先看 `renderer/src/config.js`** —— 按生态分节，注释里写清楚了每个数字是干什么的。

更细的调参速查见 [TUNING.md](TUNING.md)。

## 已知限制

- **只有 Windows x64**，没做 macOS / Linux 构建
- 窗口用了 `transparent: true`，在部分显卡驱动下会掉帧。掉帧的话可以在 `main.js` 里加 `app.disableHardwareAcceleration()` 试试
- 没买代码签名证书，所以第一次打开一定有 SmartScreen 提示
